Личный словарь с добавлением и удалением слов, очисткой таблицы и скрытием словаря. Сохранены бирюзовое оформление и переключение RU/EN по нажатию. Добавлены светлая и тёмная темы; слова и настройки сохраняются в localStorage и восстанавливаются после перезагрузки.

## Запуск

Откройте `index.html` в браузере. Установка зависимостей и сборка не нужны.

При необходимости запустите локальный сервер из папки проекта:

```bash
python3 -m http.server 8000
```

Откройте <http://localhost:8000>.
